## What today is for

You've covered connecting, files & storage, streaming, and known quirks. Friday is the day to:

1. **Pass the knowledge check.** [Take the canonical knowledge check](knowledge-check.html) — diagnostic-sequence cheat-card, bug-report rubric.
2. **Submit the assignment** — diagnose three instructor-simulated breakages and file proper bug reports.
3. **Open-ended lab time.** Catch up; ask oxtutor to re-explain anything still fuzzy.

## Self-check before Week 9

You should be able to, without notes:

- Connect to a node, detach, reconnect.
- Copy a small file with `capsule cp`; mount the shared storage pool and read a large file from it.
- Run a job with `--stream` and watch logs live.
- Diagnose a connection failure and write a bug report against the rubric.
