## What today is for

You've covered agent case studies, Capsule architecture + foundations, installation, and environments. Friday is the day to:

## Self-check before Week 8

You should be able to, without notes:

- Draw the Capsule architecture (CLI → control plane → environments → agents → nodes) and label which Phase 1 concept each component leans on.
- Run `capsule env`, `capsule node list`, `capsule node show` and explain what each returns.
- List two Module-1 install gotchas from the Lab Guide.
- Tell the difference between an *environment* and a *node*.
