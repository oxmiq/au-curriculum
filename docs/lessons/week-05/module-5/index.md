## What today is

You've finished Phase 1 — five weeks of inference engineering. Today is:

1. **Phase 1 assessment (15% of the program grade, open-book).** [Take the canonical knowledge check](knowledge-check.html). Reasoning-focused. Item bank: Problem Sets ☆ stretch problems across Sets 11–24.
