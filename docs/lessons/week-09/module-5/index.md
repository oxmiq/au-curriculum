## What today is for

You've covered first-benchmark, parameter sweeps, interactive chat evaluation, and scheduling + MCP. Friday is the day to:

1. **Pass the knowledge check.** [Take the canonical knowledge check](knowledge-check.html) — phase-timing rubric, sprint protocol.
2. **Run the timed sprint** (20-minute target): find machine → benchmark → evaluate → record.
3. **Submit the retrospective assignment** — "What surprised me about the benchmark results?" — feeds directly into the Capstone charter on Day 47.

## Self-check before Week 10 (Capstone)

You should be able to, without notes:

- Run `capsule benchmark` end-to-end on a freshly-leased node within 20 min.
- Read a curve and explain which Phase 1 concept the inflection point exposes.
- Use the chat UI to spot a config that has *better numbers but worse answers*.
- Schedule a nightly benchmark sweep and inspect the results the next morning.
